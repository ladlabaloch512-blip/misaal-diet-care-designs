# Misaal Diet Care - Website Design Demos

Six clickable demo websites for **Misaal Diet Care (MDC)**, prepared by **BIMM Global Services** from the Google Flow designs picked by the client team (Designs 2, 4, 5, 6, 8, 10).

Open the hub (`index.html`) and pick a design. Every demo is a single standalone HTML file with all 10 pages built in: Home, About, MIND Institute, Products Coming Soon, Shop, Product Detail, Cart, Checkout, Order Confirmation and Contact - with a working cart, checkout flow, colour switcher and animations.

- Design 2 - Soft Mint Wellness (classic floating header, card grid)
- Design 4 - Swiss Grid (ruled full-width header, services matrix, shop table)
- Design 5 - Academic Institute (dark gold, split clinic/institute hero, panel programs)
- Design 6 - Fresh Friendly (centred hero, oval portrait, programs rail)
- Design 8 - MDC Journal Editorial (masthead, feature article, journal listings)
- Design 10 - Minimal Centre (centred panel on sage, gold-bordered list rows)

Demo only - sample products and prices, no live orders.
